# 数据、模型与来源

## 目录口径

362 个十四经经穴条目依 GB/T 12346-2021；51 个国标奇穴条目依 GB/T 40997-2021；6 个补充条目另列。合计 419 条记录，不是 419 个唯一显示标记：双侧穴和组合穴存在多个标记。

国标编码、穴名、拼音、基本位置关系、来源页码与本项目的三维示意分别存储。WHO 361 穴目录与现行国标的差别、古歌穴序与现代穴序差异另列说明。参考入口见应用 `/sources` 和各数据文件中的 URL、版本及页码。

## 分层来源

| 层次 | 主要文件与边界 |
| --- | --- |
| 名称、编号、读音 | `national-standard.json`、`extra-standard.json`、`point-pronunciation.json`；源事实与条款索引 |
| 定位事实 | `standard-location-facts.json`；以区域、解剖关系、方向与距离等结构化事实表示，不附完整标准 PDF |
| 古籍与传统主治 | `classics.ts`、`primary-indication-scan.json` 等；古籍原文节选、整理摘要和来源记录分开 |
| 来源索引 | `point-reference.json`；早期参考 TARA 的事实关键词与页码索引，未包含其原始 CSV 或现代书籍全文 |
| 配穴 | `combinations.ts` 等；公开文献与古籍用穴的学习记录，不是个体治疗建议 |
| 示意几何 | `mesh-registration.json`、`*course.json`、`luo-surface.json`；项目整理的绑定、区域曲线和出处说明 |

事实、通用名称、古籍原文及外部权利人的作品不因本项目采用 AGPL 而产生新的排他权利。对于第三方来源，请按原发布方条件取得和使用；链接不等于再分发授权。

## 人体模型

当前人体来自 MakeHuman Community 的 CC0 核心资产，固定原始提交 `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`。提取 body 分组、排除辅助对象、归一化后采用既有学习体位。具体来源、转换参数、输入输出哈希见 `public/models/model-provenance.json`。

双手甲面参考通过与该底模相同的源拓扑识别；这是模型内部的方向参照，不是人体甲沟的临床标注。其它外部骨骼/手部模型曾用于独立研究，没有打包成当前运行人体。

## 审校与贡献

新的校订需记录源版本、具体页码或条款、改动对象与验证方法。3D 改动需要与保留底模建立对应，检查双侧及经络依赖。区域模板、表面吸附、作者材质分区、真实骨性参照是不同层次的证据，不能混称为“已校准”。

目前全身逐穴解剖审校未完成。欢迎带着可复现证据提交校订；请勿上传无再分发授权的书籍扫描、数据库、模型权重或患者信息。

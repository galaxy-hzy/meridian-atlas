# Learning body asset

CC0 MakeHuman body from commit a8bc2d54ff0ac92e78ff71431b1023eda42bf482.
Source: https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data/3dobjs/base.obj
Asset license: https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.ASSETS.md

The body group was extracted, normalized and posed using the pinned CC0 rig
weights. Helpers were excluded. See model-provenance.json for exact inputs,
transforms, joint centers and the output SHA-256, and docs/DATA.md in the
project root for the preparation and registration workflow.

This generic body and its point registration have not been clinically validated.
